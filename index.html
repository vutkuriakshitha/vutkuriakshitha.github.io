03 · Selected work

01 · Team of 3 · 3 months

EZTAP

A hyperlocal task marketplace: customers post tasks, nearby helpers apply, and the job moves from hiring to completion and a review.

🏆 1st Prize, NewGen IEDC IdeathonLive on Firebase

The problem

Everyday tasks are hard to hand off to someone trustworthy nearby, quickly.

What I built

A full-stack web app with one account for everyone: switch between getting tasks done and earning as a helper. Customers post tasks with a category, budget and city, and helpers browse and apply with a message.

Highlights

  • Hiring flow enforced by Firestore security rules: open, assigned, in progress, then completed or cancelled.
  • Trust levels (Verified, Trusted with admin-approved proof, Community trusted through vouches), star reviews and public helper profiles.
  • Google and email sign-in, in-app notifications and an admin review page.

02 · Solo · 3 months

TimelySync

An AI-assisted deadline manager that reads notices and circulars, finds every date, and turns the ones that need action into tasks.

Built solo, end to endOCR + LLM + ML

The problem

Deadlines hide inside notices, circulars and emails, and it’s easy to miss which dates actually need action.

What I built

Three services: a React UI, a Spring Boot API with JWT security on MongoDB Atlas, and a FastAPI AI service. Upload a PDF, image or text and it extracts each date with its meaning, the exact source sentence and a confidence score.

Highlights

  • Grounded extraction: LLM output is checked against the document (evidence must appear, dates must be real, duplicates merged, past dates get no task), with a classic ML fallback so uploads never fail.
  • Failure-risk and impact prediction with scikit-learn, plus a dashboard, academic planner and post-deadline analysis.
  • Unit tests and an evaluation script for date recall and precision; deployed on Render with MongoDB Atlas.

03 · Team of 3 · Final-year project

CrowdPulse

A crowd-safety platform for public-venue control rooms that turns CCTV video into zone-level crowd intelligence.

In progressPresented at the Major Project Review

The problem

Control rooms need to know early when a crowd is becoming unsafe, and why.

What I built

YOLOv8 person detection (with an OpenCV HOG fallback) and a centroid + IoU tracker feed a FastAPI backend (JWT, bcrypt, role-based access) and a Next.js dashboard with a live zone map and what-if simulation.

Highlights

  • Dynamic Crowd Risk Score (DCRS) combines density, speed drop, opposing flow and exit pressure into Green, Yellow, Orange and Red bands.
  • Explainable Risk Attribution (ERA) ranks the factors behind each alert.
  • Gradient Boosting action recommendations with a safety filter that blocks unsafe options, such as closing the last exit.
  • Operators Accept or Dismiss each recommendation, and every decision is logged.
